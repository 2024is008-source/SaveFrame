# SaveFrame (Instagram Downloader) — Master Design System (`MASTER.md`)

Generated by synthesizing **UI/UX Pro Max** (design-system architecture, accessibility priority order, touch targets, resilient typography, and form validation patterns) with **Taste Skill v2 (`design-taste-frontend`)** (anti-slop editorial art direction, restrained surface hierarchy, 2-line max headlines, zero resting drop shadows, and real browser verification).

---

## 1. Visual Direction & Conflict Resolution

| Dimension | UI/UX Pro Max Recommendation | Taste Skill v2 (`design-taste-frontend`) Rule | Final Synthesized Decision |
| :--- | :--- | :--- | :--- |
| **Surface Palette** | High-contrast light mode (`#FFFFFF` / `#F8F9FD`) with semantic primary (`#7C3AED`), secondary (`#EC4899`), and accent (`#F97316`). | Keep 90%+ of the viewport calm archival/clean white; avoid full-page gradients, neon glows, or assistant-slop purple washes. | **92% Clean White & Soft Alabaster (`#FFFFFF` / `#F8F9FD`)**. Reserve the violet-pink-orange spectrum strictly for the Main Downloader Panel accent bar, active media tab, and primary CTA. |
| **Elevation & Borders** | Clear visual grouping for forms, tabs, and result cards. | No drop shadows on elements at rest; use crisp structural `1px` borders (`#E9EAF0`) and tonal surface steps. Shadows reserved only for floating dropdowns/modals. | **Flat Tonal Surfaces + `1px solid #E9EAF0` Borders** at rest. Floating header dropdowns and modals use a subtle architectural elevation. |
| **Typography** | **Plus Jakarta Sans** (headings) + **Inter** (body & UI controls) with clear modular scale and `tabular-nums`. | Maximum 2 typefaces, `clamp()` display sizing, tight heading tracking (`-0.025em`), max 2 lines per heading at all widths, `tabular-nums` for technical specs. | **Plus Jakarta Sans** (`600`/`700`, `-0.025em`) + **Inter** (`400`/`500`/`600`, `tabular-nums`), engineered so every `h1`–`h3` fits within 2 lines from `360px` to `1440px`. |
| **Feature & Step Layout** | Scannable 3-step guide and factual feature breakdown. | No `01 / 02 / 03` badge slop or 3×2 icon-in-tinted-square card grids; use semantic `<ol>` ledgers and factual specification matrices. | Semantic `<ol>` 3-Step Process Ledger with custom inline SVG schematics + Factual Capability Matrix & 2-Column Utility Ledger. |
| **Touch & Accessibility** | Minimum `4.5:1` AA text contrast, `44×44px` touch targets, `:focus-visible` rings, `aria-live` feedback, `prefers-reduced-motion`. | Every interactive control must respond visibly; zero horizontal overflow (`scrollWidth <= clientWidth`) at `360px`, `390px`, `430px`, `768px`, `1024px`, `1440px`. | All buttons, tabs, paste/clear controls, and accordions enforce `min-h-[44px]`, WCAG AA contrast (`#171827` primary text = `17.4:1`, `#525866` muted text = `7.1:1`), and full keyboard operability. |

## 3. Responsive Breakpoints & Viewport Rules

- **360px / 390px / 430px (Mobile)**:
  - Compact hero padding (`24px` top, `16px` outer margins).
  - 5-tab Media Tool Selector uses a single 5-column compact grid (`min-h-[48px]`) with stacked icon + label so all 5 categories are immediately visible and tappable with zero horizontal scroll.
  - URL input bar stacks cleanly on mobile: full-width input row with inline Clear button on top, followed by a 2-column action row (`Paste Link` + primary `Download / View` CTA) with `48px` tap height.
- **768px (Tablet)**:
  - Unified horizontal input workbench (`Input` + `Paste` + `Clear` + `Primary CTA` in one structured row).
  - 2-column result preview layout (Media frame on left, quality specifications & download actions on right).
- **1024px / 1440px (Desktop)**:
  - `1120px` max-width container with equal outer margins, crisp `1px` architectural grid alignment, and full desktop dropdown navigation.
