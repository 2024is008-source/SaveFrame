Use a ZIP when you want the available images from one TikTok photo post together. The archive packages the actual downloaded files; it is not a video of the slideshow, and it does not include a separate copy of the in-app soundtrack.

## Prepare the complete set

1. Paste a public photo post link into the [photo downloader](/photo-downloader).
2. Check the creator, thumbnails and number of slides.
3. Choose Download All to request the complete available set.
4. Wait while the images are downloaded and packaged.
5. Save the completed ZIP through your browser.

The carousel interface can also download an individual image. If you select only some slides, check the button label so you know which selection you are requesting.

## Extract before importing

Open the saved archive with your device’s file manager or archive utility and extract it to a normal folder. The exact command varies by device. Gallery and editing applications may not read images directly from inside a ZIP.

The archive uses ordered filename prefixes to help preserve slide order. Sort the extracted files by name before renaming or importing them. If your gallery sorts by a different field, its display order may differ from the post’s sequence.

## Check the result

Compare the extracted image count with the number of slides shown in the downloader. Open a few images and check their dimensions before deleting a temporary working copy. A larger ZIP does not automatically mean higher image quality.

## If packaging fails

One unavailable slide, a source restriction or the file-size limit can prevent a complete archive. Try an individual image to narrow down the problem, then use the [download troubleshooting steps](/blog/tiktok-downloader-not-working). Do not treat a partial set as a complete backup without checking which slides are present.
