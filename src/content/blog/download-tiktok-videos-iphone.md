On iPhone, a browser download and a video in the Photos library are different things. A successful download can be in Files even when nothing new appears in Photos. Start by finding the saved file before trying to download the same post again.

## Prepare the video

1. Copy the individual public TikTok video link.
2. Open the [video downloader](/video-downloader) in Safari or your preferred browser.
3. Paste the link, inspect the preview and choose an available MP4 format.
4. Select the download button in the result and wait for preparation.
5. Confirm the browser’s file-download prompt if one appears.

If clipboard access is unavailable, press in the link field and use Paste. You do not need to sign in to TikTok through TikSaveMP4.

## Find the downloaded file

Apple explains that internet downloads can be found in the Downloads folder in the Files app. Your selected download location determines whether that folder is under iCloud Drive or local storage. See [Apple’s instructions for finding downloads](https://support.apple.com/en-us/102440).

## Move a compatible copy to Photos

Open the downloaded MP4 in Files and inspect its sharing options. If Save Video is available, you can use it to add a compatible copy to Photos. If it is missing, check whether the file plays correctly and whether that file format is supported by your device.

## When the file does not appear

Check the browser download list for a pending, cancelled or failed transfer. A completed server preparation does not by itself mean your browser finished saving the file. Keep enough free storage and retry an expired download by inspecting the link again.

For photo posts, follow the [slideshow guide](/blog/download-tiktok-photo-slideshows); an image ZIP should be extracted before you try to import its contents.
