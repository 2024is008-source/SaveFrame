First identify where the process stopped: link inspection, file preparation or browser delivery. These stages fail for different reasons. A clear error message is more useful than repeatedly submitting the same link, especially when TikTok is restricting requests.

## Check the link

Use an individual public video or photo post URL, or an official TikTok short link. Profile pages, live streams and links from unrelated domains are unsupported. If the input is rejected immediately, follow [how to copy the correct post link](/blog/how-to-copy-tiktok-link).

## Check source access

A post that opens in a signed-in TikTok app may still be unavailable to a public downloader. Deleted posts, private accounts and login restrictions can prevent inspection. Regional or network restrictions can also affect an otherwise public link.

If the message says TikTok is limiting access from the server, wait and try again later. Changing the download quality does not remove a source-level restriction. The site does not request your account password or login cookies.

## Check preparation

If the preview appears but file preparation fails, try an individual supported item and read the error. A large archive, missing source file or server runtime problem can stop preparation. A functioning preview does not guarantee that the signed source URL remains available indefinitely.

## Check browser delivery

Look in the browser’s download list for a pending or failed transfer. Keep the tab open while preparing the file and make sure your device has free space. Temporary download files expire; inspect the post again if an older prepared link has expired.

## Report a useful problem

Use [Contact](/contact) and include the public link, device, browser, error text and stage where the failure occurred. Do not send passwords or private account data. If you own the content and need an urgent copy, use your original recording or editing export rather than depending on a platform download.
